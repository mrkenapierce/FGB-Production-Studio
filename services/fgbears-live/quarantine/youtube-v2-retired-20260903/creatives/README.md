# YouTube v2 local creatives

Optional Lovable-selected destination creatives are installed here as PNG files.

Naming contract: `<creative_key>.png`, where `creative_key` contains only lowercase
letters, digits, `_`, and `-`.

The worker never downloads creative assets from Lovable or another remote URL.
Lovable selects a key; Oracle renders only locally installed assets. Unknown keys fail
transparent.

`yt_rumble_trivia_redirect` remains a built-in locked creative generated by
`../../tools/build-youtube-rumble-trivia-card.py`.
